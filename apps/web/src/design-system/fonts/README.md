# Fonts

- Source Serif 4 (variable, weight 200–900, optical size 8–60, roman + italic), by Frank Grießhammer for Adobe. SIL Open Font License 1.1. Latin subset from `@fontsource-variable/source-serif-4` 5.3.0 (opsz files).
- Figtree (variable, 300–900, roman + italic), by Erik Kennedy. SIL Open Font License 1.1. Same files as Pyxis.
- JetBrains Mono (variable, 100–800), by JetBrains. SIL Open Font License 1.1. Same file as Pyxis.

Latin covers Italian and English. Bundle them with the app; nothing loads from the network. Add `latin-ext` subsets from Fontsource if a book needs more languages. KaTeX keeps its own fonts.
